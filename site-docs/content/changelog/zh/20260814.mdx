版本 0.80.0

### ✨ 新功能

- 文件预览现在可直接读取工作区中的文件，支持常见文本与图片格式，也可以预览未跟踪文件和 Agent 生成的临时文件。
- 桌面终端新增复制与粘贴操作，可通过右键菜单操作，并支持快捷复制选中的内容。

### 🐛 修复与改进

- 修复 Windows 上启动 Codex 或 Grok 时可能意外弹出终端窗口的问题。
- 改进 Codex 会话的错误处理、标题和分支名称生成，避免将 Provider 错误内容误用为标题，并正确沿用所选模型配置。
- 修复会话图片缩略图可能无法加载或导出的问题，并在缩略图生成失败时自动回退到原图。
- 提升 @ 提及菜单的可靠性，修复 Skill、Issue 和 Pull Request 在重新打开、切换或搜索后可能失效或显示旧结果的问题。
- 修复已归档会话在应用启动同步期间重新出现在列表的问题。
- 改善通知在浅色主题下的可读性和操作按钮布局。
- 修复侧边栏文件树中已展开的文件夹可能意外折叠的问题。
- 改进 Windows 内存压力判断，减少系统仍有可用提交空间时错误重启 Agent 的情况。
- 提升短暂断线后的同步恢复可靠性，减少工作区或会话状态恢复不完整的问题。
