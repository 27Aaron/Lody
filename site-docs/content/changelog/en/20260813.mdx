Version 0.79.2

### ✨ New

- Added copy and paste actions to the desktop terminal through its context menu, including a keyboard shortcut for copying selected text.

### 🐛 Fixes and Improvements

- Fixed session image thumbnails sometimes failing to load or export, with an automatic fallback to the original image when thumbnail generation is unavailable.
- Improved the reliability of the @ mention menu, including skills, issues, and pull requests after reopening, switching, or searching.
- Improved session title and branch name generation so Agent errors are not used as titles and the selected model configuration is preserved.
- Fixed archived sessions reappearing in the list during app startup synchronization.
- Improved notification readability in the light theme and the layout of action buttons.
